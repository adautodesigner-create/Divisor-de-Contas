# Divisor de Contas

Aplicativo web para dividir a conta do bar ou restaurante por item, com taxa de serviço, couvert e resumo para o WhatsApp.

**Acesse:** https://adautodesigner-create.github.io/Divisor-de-Contas/

## O que ele faz

- Divide cada item entre quem consumiu, em partes iguais ou diferentes.
- Taxa de serviço pelo consumo ou igual para todos, com opção de alguém não pagar.
- Couvert por pessoa e outras cobranças.
- A soma de todos sempre fecha com o total da conta, no centavo.
- Grupos salvos para as saídas de sempre.
- Ordena os itens e mostra o que cada pessoa consumiu.
- Funciona sem internet e pode ser instalado no celular (menu ⋯ → Instalar no celular).

## Publicar uma versão nova

Os dados ficam salvos só no aparelho de cada pessoa. Ao alterar o app, aumente o número de `VERSION` na primeira linha do `sw.js` (por exemplo, `divisor-v3` → `divisor-v4`) para os celulares receberem a atualização.
